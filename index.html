MAGIC DUEL 北欧魔導決闘

1対1の決闘。キャラクターは6人、技は開戦のたびに50種類から抽選。

遊び方
  1. 6人のキャラクター（剣士2・戦士1・魔法職3）から1人を選ぶ。能力値はキャラクターごとに決まっている。
  2. 一人旅では残りの5人に順番に挑む。負けても同じ相手に何度でも挑み直せる。
  3. 開戦のたびに技を3つ引く。近接職は近接の技25種、魔法職は魔法25種から。レアリティはコモン・レア・エピック・レジェンドの4段階。魔法職は転移も標準で持つ。
  4. 舞台は3つ（炎の闘技場・氷河の湖・雷鳴の丘）。それぞれ動くギミックがある。先に2ラウンド取った方の勝ち。

操作（スマホ）

画面の左側触った所にスティックが出る。奥まで倒すと走る
画面の右側をなぞる視点移動
攻撃（右下の大きいボタン）通常攻撃。長押しで溜め、離して放つ（剣は踏み込み突き、斧は跳び込み）。押したまま指を動かすと照準も動く
技・魔法ボタン（攻撃の上）技・魔法ごとの専用ボタン。押して溜め、離して放つ。切り替えは不要
跳 / 障壁ジャンプ / 押している間、前に障壁を張る（出した直後はパリィ）

操作（キーボード＋マウス）

WASD / Space / Shift移動 / ジャンプ / 走る
左クリック 長押し→離す選んでいる技を溜めて放つ
1 / 2 / 3 / 4杖: 魔弾 / 抽選魔法2つ / 転移。剣・斧: 通常攻撃 / 技2つ（剣は回転斬り・踏み込み斬り、斧は大旋風・雄叫び）
右クリック 長押し前面障壁。押しながらホイールで大きさ
Q 長押し全方位ドーム障壁（範囲攻撃・毒霧用。マナ消費大）
ホイール集束：上＝細く遠く / 下＝広く近く
F奥義・グングニル（ゲージ満タン時）

コツ

  • 剣・斧は振りかぶりが見える。見てから障壁を張れば防げ、出した直後ならパリィ。斧は障壁を大きく削る。
  • 杖は近接に詰められたら転移で離れる。剣は踏み込み斬り、斧は跳び込みでまた詰める。
  • 頭に当てるとクリティカル1.5倍。雷は飛んでいる相手を撃ち落とす。
  • 炎の闘技場の炎の帯と、雷鳴の丘の落雷の輪は、どちらにも当たる。相手を追い込むのに使える。
  • 闘技場は炎の輪。20秒後から縮むので、逃げ回るだけでは勝てない。
